He shows Original Table 3 from an ImageNet paper comparing ResNet-50 and ResNeXt-50 models, where each row lists a model, its configuration (setting), and top-1 error rate (23.9% for ResNet-50 1x64d, 23.0% for ResNeXt-50 2x40d). Using MinerU, the tool merges the two model names into one cell spanning both rows ('ResNet-50ResNeXt-50'), keeping the two error rates separate — so importing would incorrectly assign the same combined name to both results. In contrast, using Docling on the same page keeps a separate model name on each row, correctly preserving 23.9% with ResNet-50 and 23.0% with ResNeXt-50, along with their configurations.
