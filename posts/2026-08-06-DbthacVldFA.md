## Caption

Extracting every workflow from agent history and using skills for all your personalized knowledge creates overlapping trigger rules.

If you stick with 1 skill per type of activity it grows until it's too big to manage with conditional logic in the prompt. If you keep splitting it you eventually end up with overlapping triggers. Either way, the model gets a longer list of conditional prompts.

Most of the time, this doesn't happen because a workflow is extracted to a skill but it's not updated or maintained so if never really serves the purpose it was supposed to very well.  Which is even worse.

Once this trigger list gets large, add retrieval instead.
