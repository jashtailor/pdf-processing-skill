## Caption

New document news! Papers with Code is now using Chandra, thanks to Datalab, to accept non-arXiv PDFs for submissions. This is for their Chat with Research Paper feature.

On Papers with Code, a page has an abstract, benchmark information, and, of course, links to code and Hugging Face as well. Understanding the paper takes quite a lot of time, and it's helpful to have a chatbot and an LLM to help with that.

For many of the arXiv papers, it's able to convert HTML to Markdown, but now they can do it with PDFs that aren't exclusive there. The PDF goes to Chandra, it saves to Markdown, and then the research assistant (the Chat with Paper feature) uses that Markdown.

This is a good example of how, if you have a good document processing pipeline with a good OCR model, you can open it up to a lot more sources and work with a lot more data. I'm pretty excited about this one because it just means it's going to be a little bit easier and a little bit more accessible to learn what's going on with new papers and new releases.
