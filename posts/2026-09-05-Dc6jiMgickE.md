## Caption

New document news. ParseBench hit 1.0. ParseBench is a document parser benchmark to test how well parsers work across text, formatting, tables, charts, and page locations. All of these matter when you need to point back to the source of a result and make sure that it is accurate.

Version 1.0 fixes scoring and provider bugs, adds rules and visual checks, and makes ParseBench easier to install. So it is a nice release.

The most important thing, however, is that 0.2 and earlier scores are not compatible with 1.0. If you use ParseBench and have old benchmarks, make sure to rerun them before running a new model on 1.0 and comparing. Rerun your old experiments on 1.0 and you will be good to go.
