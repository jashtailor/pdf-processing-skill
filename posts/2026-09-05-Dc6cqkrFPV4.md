## Caption

New document news. Nutrient released a new state model that predicts whether a field or checkbox is blank or filled.

Normally you would use a field detector, take each detected text box, checkbox, or signature, and send that small rectangle to the state model for the empty-versus-filled check. This is often very difficult, but very critical. For example, a signed legal document and an unsigned legal document should be treated very differently.

I ran it on a sample blank text field, which scored 0.007 filled. A typed text field scored 0.892 as filled. A checked box only scored 0.416. This one seemed pretty clear that it was checked, so it did not do quite as good a job there as I would like. The signature field with some lines in it scored essentially 1.0, which is what I would expect.

Overall, it seems pretty good. If I were to use this, I would probably do a little more checking around the checkboxes to see what needs to be done to handle that correctly and better. This is not a benchmark, but just a quick second-step check for me to do. If you use this in an application, I hope to hear how it works for you.
