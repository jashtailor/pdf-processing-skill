## Caption

Agent memory is not one thing. It is a family of retrieval systems.

A project wiki, a conversation with a friend, an X post, and a code snippet should not be stored, chunked, or retrieved the same way. Some need keyword search, some semantic search, and some are fine with grep.

They also need lifecycle rules: what gets stored, updated, deleted, and when it should be retrieved.

A single memory bucket may look fine but it gets cluttered over time.

Design memory like you would a complex retrieval system
