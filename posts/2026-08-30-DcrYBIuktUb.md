## Caption

New document news! Unstructured can now return code blocks as code snippet elements instead of just ordinary text.

In their new documentation, they show an API guide that they ran through the parser. We can see a title, narrative text for prose, a code snippet where the actual code is, and then another narrative text cell.

This is pretty cool because now a support assistant, for example, can get all the prose and the explanation and process the code individually without anything extra: syntax highlighting, a copy button, a syntax checker, and all the things you might want to do with code. You don't need a separate splitter to figure out how to split the code versus prose.

This element type doesn't give you free citations or do any of that stuff for you, but it means you'd have one less thing to worry about in your code if this works really well on your documents.
